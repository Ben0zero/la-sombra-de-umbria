# 🎲 La Sombra de Umbría

Aventura conversacional estilo **D&D** en un solo archivo HTML: elige tu profesión, tira dados, juega cartas de acción y sube la torre para enfrentar a la Sombra.

## 🎮 Jugar

- **Online:** https://ben0zero.github.io/la-sombra-de-umbria/
- **Local:** abre `index.html` en tu navegador, o ejecuta `node servidor-local.js` y entra a http://localhost:4321

## ✨ Qué tiene

- **Creación de personaje:** tiras 4d6 (descartas el más bajo) y eliges profesión: 🛡️ Guerrero, 🗡️ Pícaro, 🔮 Mago o 🎭 Bardo.
- **Cartas por profesión** que se desbloquean al subir de nivel con ⭐ XP.
- Retos con tirada de **d20 + bonificadores**, críticos y pifias.
- **Gestión de dados:** reserva limitada (empiezas con 2) y opción de ir **a pulso** con un d6 gratis.
- **Enemigos** con barra de vida, tienda, decisiones ramificadas y un jefe con dado propio (d3).
- **Música celta** generada en vivo (sin archivos de audio).
- **Guardado automático** (localStorage).

## 🛠️ Tecnología

HTML + CSS + JavaScript en un único `index.html`, sin dependencias ni assets externos. La banda sonora se sintetiza con la **Web Audio API**.
